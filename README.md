# YOUR NAME — Academic Website

A zero-build static academic website designed for GitHub Pages.

## Why this version is beginner-friendly

- No terminal required.
- No npm, Ruby, Jekyll, or build step.
- HTML + CSS + a tiny amount of JavaScript.
- Works with GitHub Pages publishing directly from the `main` branch.
- Mobile-friendly and accessible.
- Easy to replace placeholder text by searching for `YOUR`.

## Site map

- `index.html` — landing page
- `research.html` — research agenda, publications, talks
- `projects.html` — research/code/data projects
- `notes.html` — public research notebook / wiki index
- `notes/example-note.html` — sample note
- `cv.html` — web CV
- `404.html` — custom not-found page
- `assets/css/styles.css` — visual design
- `assets/js/main.js` — mobile menu + footer year
- `assets/img/monogram.svg` — abstract site mark

## First edits

Search the whole project for:
- `YOUR NAME`
- `YOUR-USERNAME`
- `YOUR.EMAIL@EXAMPLE.COM`
- `YOUR-LINKEDIN`
- text inside `[SQUARE BRACKETS]`

Do not publish sensitive personal data, unpublished confidential material, private datasets, API keys, passwords, access tokens, or information restricted by an IRB / data-use agreement.

## Add a PDF CV

1. Put your PDF at `assets/cv.pdf`.
2. Open `cv.html`.
3. Find:
   `<a class="button primary" href="#">Download PDF CV</a>`
4. Change it to:
   `<a class="button primary" href="assets/cv.pdf">Download PDF CV</a>`

## Design intent

The palette and visual language are inspired by a controlled collision of:
- formal academic publishing,
- neon industrial interfaces,
- punk/graffiti energy,
- cyan / magenta / violet accents.

It intentionally avoids copyrighted character art, logos, or direct Arcane/League assets so the website reads as an original academic identity rather than a fan site.
