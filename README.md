# Dark Academia Academic Portfolio

A simple academic portfolio designed for GitHub Pages.

## What to edit first

Open `index.html` and replace:

- `YOUR NAME`
- `YOUR-USERNAME`
- `YOUR FIELD`
- `YOUR RESEARCH AREA`
- research/project placeholder text
- `you@example.com`

Then put your CV PDF at:

`assets/cv/YOUR-NAME-CV.pdf`

If your actual file has a different name, update the two CV links in `index.html`.

## Publish with GitHub Pages

1. Create a repository named exactly `YOUR-USERNAME.github.io`.
2. Upload these files into the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Visit `https://YOUR-USERNAME.github.io`.

## Suggested academic sections to add later

- Publications / working papers
- Teaching
- Research experience
- Presentations
- Data/software
- Blog or research notes
- Contact / links (ORCID, Google Scholar, LinkedIn)

## Design notes

The design intentionally uses:
- near-black background
- oxblood/dark-red accents
- restrained purple
- serif display typography
- monospace technical details
- minimal gothic/Frankenstein atmosphere without sacrificing academic readability
