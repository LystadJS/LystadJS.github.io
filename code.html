02 / driftmapR

driftmapR

R package · In development

driftmapR is my R-package development project for comparing repeated low-dimensional maps. The work examines how to distinguish coordinate changes from structural change and carry uncertainty into that comparison.

When a map moves,
did the system change?

A map can rotate or shift without the underlying system changing. Alignment addresses that ambiguity; it does not, on its own, establish substantive change.

For anticipatory analysis, this is a prior question: before interpreting movement as a warning, establish whether it reflects the system or the way the map was constructed.
